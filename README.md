# 선택의 서가

세 편의 선택형 텍스트 소설을 제공하는 정적 PWA 배포 저장소입니다.

- 유리 계절의 고백
- 빛이 닿지 않은 사진
- 마지막 편지를 대신 쓰는 일

## 공개 사이트

https://dlals2061-web.github.io/novels-library/

이 저장소에는 GitHub Pages 배포에 필요한 정적 파일만 포함합니다. 원고 설계, 내부 검수 기록, 다른 비공개 프로젝트는 포함하지 않습니다.

검색 결과 노출과 규칙을 준수하는 크롤러의 수집을 줄이기 위해 `robots.txt`와 각 HTML의 `noindex, nofollow` 메타 태그를 사용합니다. 이는 접근 권한을 제한하는 보안 기능은 아닙니다.
